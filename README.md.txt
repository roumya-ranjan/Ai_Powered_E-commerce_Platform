# AI-Powered E-Commerce Platform

A full-stack e-commerce platform built using Spring Boot Microservices, React, MySQL, Kafka, Redis, Docker, and AI-powered features.

## Tech Stack

- Java 17
- Spring Boot Microservices
- Spring Cloud Gateway
- Eureka Server
- React.js
- MySQL
- Redis
- Kafka
- Docker
- JWT Authentication
- Payment Gateway
- AI Integration

Project initialization completed.
